# حِمى | HIMA — GitHub Pages

نموذج أولي تفاعلي لمنظومة التأمين وإدارة مخاطر الفعاليات الكبرى والتجمعات الحاشدة.

## الملفات
- `index.html`: نقطة تشغيل الموقع.
- `css/style.css`: الهوية البصرية والتنسيق المتجاوب.
- `js/app.js`: التفاعلات والوظائف التجريبية.

## رفع المشروع إلى GitHub
1. فك ضغط الملف ZIP على جهازك.
2. افتحي مستودع GitHub الذي أنشأتيه.
3. اختاري Add file ثم Upload files.
4. ارفعي **محتويات المجلد** (index.html ومجلدي css وjs وREADME.md) إلى جذر المستودع، وليس ملف ZIP وحده.
5. اضغطي Commit changes.
6. من Settings ثم Pages اختاري Deploy from a branch، ثم `main` و`/(root)` واضغطي Save.

## تنبيه
الأسعار والتذاكر والشهادات والحوادث والمطالبات في هذا النموذج افتراضية. لا يوجد تكامل فعلي مع Webook أو بوابة دفع أو شركة تأمين، ولا يصدر وثائق تأمين حقيقية. البيانات تجريبية داخل الصفحة ولا تحفظ في قاعدة بيانات.
