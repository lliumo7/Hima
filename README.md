# HIMA — النسخة المطوّرة

هذه النسخة مبنية على التطبيق المعتمد المرفوع من المستخدم، مع الحفاظ على بوابة المستفيد والصفحة الرئيسية والهوية البصرية والصور.

## محتويات المشروع
- `index.html`
- `style.css`
- `app.js`
- `assets/events/` صور الفعاليات

## التحديثات
- تطوير بوابة منظم الفعاليات لتسجيل الفعالية، تقييم مؤشرات المخاطر والسلامة، اختيار تغطيات الفعالية، وإرسال طلب تأمين.
- تطوير بوابة شركة التأمين لاستقبال طلبات تأمين الفعاليات ومراجعتها وقبولها أو رفضها مع سبب/ملاحظات وقسط مقترح.
- عند قبول الطلب تصدر وثيقة تجريبية وتظهر في قائمة الوثائق.
- مطالبات المستفيدين بقيت منفصلة عن طلبات تأمين الفعاليات.

## النشر
ارفع محتويات هذا المجلد مباشرة إلى جذر مستودع GitHub Pages، بحيث يكون `index.html` في الجذر.

## تنبيه
هذه تجربة أمامية (Front-end demo). البيانات مشتركة خلال جلسة الصفحة فقط، ولا يوجد خادم أو قاعدة بيانات أو تكامل حقيقي مع شركة تأمين. مؤشر المخاطر توضيحي وغير معاير ولا يستخدم للاكتتاب أو قرارات السلامة الفعلية.
