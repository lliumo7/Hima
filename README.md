# HIMA | حِمى — تحديث واجهات بوابتي المنظم وشركة التأمين

هذه النسخة مبنية على الملف الذي زوّدني به المستخدم: `HIMA_Same_App_Organizer_Insurer_Upgrade_Icons_Updated(1).zip`.

## ما تم تحديثه
- إضافة شاشة رئيسية مستقلة لبوابة منظم الفعاليات مع ترحيب وبطاقات خدمات ومؤشرات مختصرة.
- إضافة شاشة رئيسية مستقلة لبوابة شركة التأمين مع ترحيب وبطاقات خدمات ومؤشرات مختصرة.
- إضافة صفحات مستقلة لمتابعة طلبات المنظم ووثائقه.
- فصل مطالبات المستفيدين في صفحة مستقلة داخل بوابة شركة التأمين، مع إبقائها منفصلة عن طلبات تأمين الفعاليات.
- إضافة روابط عودة واضحة إلى الصفحة الرئيسية لكل بوابة.
- الحفاظ على ملفات الأيقونات الأصلية `hima-icons.js` واستدعائها كما في النسخة المرفوعة.
- إضافة تنسيقات متجاوبة للجوال والآيباد والكمبيوتر، مع دعم العربية والإنجليزية عبر آلية الترجمة الموجودة.

## الملفات
- `index.html`
- `app.js`
- `style.css`
- `hima-icons.js`
- `assets/events/` صور الفعاليات

## ملاحظات مهمة
- لم يتم تعديل تصميم أو تدفق بوابة المستفيد عمدًا.
- لم يتم تغيير نموذج تأمين الفعالية أو آلية قرار شركة التأمين.
- طلب تأمين الفعالية مستقل عن تأمين التذكرة ومطالبات المستفيدين.
- بيانات الطلبات في هذا النموذج الأولي محفوظة في حالة الصفحة الحالية فقط، وليست قاعدة بيانات مشتركة أو تخزينًا دائمًا.
- هذه تجربة توضيحية وليست إصدارًا لوثائق تأمين فعلية أو تكاملًا مع شركة تأمين.

## النشر
ارفع محتويات الملف المضغوط إلى جذر المشروع في Replit أو GitHub Pages، مع الحفاظ على مجلد `assets` وملف `hima-icons.js` بجانب `index.html`.
