# حِمى | HIMA — GitHub Pages

نموذج أولي تفاعلي لمنظومة التأمين وإدارة مخاطر الفعاليات الكبرى والتجمعات الحاشدة.

## تجربة الدخول الجديدة
عند فتح الموقع تظهر صفحة اختيار البوابة:
- **المستفيد:** استكشاف الفعاليات، الحجز، الحماية الاختيارية، المحفظة والمطالبات.
- **منظم الفعالية:** إدارة الفعالية ومؤشرات المخاطر وطلب التأمين.
- **شركة التأمين:** مراجعة التغطيات والحوادث والمطالبات.

كل بوابة تعرض قائمة تنقل وصفحاتها فقط. يمكن العودة إلى شاشة اختيار البوابة من زر «تغيير البوابة».

## الملفات
- `index.html`: واجهات الموقع.
- `style.css`: الهوية البصرية والتنسيق المتجاوب.
- `app.js`: التفاعلات والوظائف التجريبية.

## رفع المشروع إلى GitHub
1. فك ضغط الملف ZIP.
2. ارفعي محتويات المجلد الأربعة إلى جذر المستودع، مع استبدال النسخة السابقة.
3. اضغطي Commit changes.
4. تأكدي من إعداد GitHub Pages على `main` و`/(root)`.

## تنبيه
هذا نموذج تجريبي ببيانات افتراضية. لا يوجد تكامل فعلي مع منصات التذاكر أو بوابة دفع أو شركة تأمين، ولا يصدر وثائق تأمين حقيقية. الدخول إلى البوابات للتجربة فقط ولا يمثل نظام مصادقة أو صلاحيات إنتاجيًا.


## تحديث V6 — تنقل بأسلوب التطبيقات
- شريط تنقل سفلي للمستفيد على الشاشات الصغيرة بخمس وجهات: الرئيسية، الفعاليات، تذاكري، مطالباتي، حسابي.

## HIMA V7 — agreed customer navigation layout
- Customer header is simplified to brand, language selector and hamburger menu.
