# حِمى | HIMA — تحديث التنقل الموحد V8

هذه نسخة نموذج حِمى بعد توحيد زر القائمة الجانبية في جميع صفحات النموذج.

## ما تغير
- زر الثلاث شرطات ثابت في رأس الموقع ويظهر في جميع الصفحات.
- القائمة تفتح من جهة اليمين وبعرض مناسب، ولا تغطي الشاشة بالكامل.
- القائمة تجمع روابط المستفيد والمنظم وشركة التأمين في مجموعات واضحة.
- أضيفت روابط مباشرة إلى أقسام الفعالية والمخاطر والحوادث والمطالبات والوثائق.
- إخفاء شريط التنقل الأفقي القديم حتى لا تتكرر وسائل التنقل.
- الحفاظ على صفحات النموذج ووظائفه الحالية وألوان حِمى.
- القائمة قابلة للإغلاق بزر الإغلاق أو بالنقر خارجها أو بمفتاح Escape.

## النشر على GitHub Pages
ارفعي ملف `index.html` إلى جذر المستودع واستبدلي النسخة السابقة. هذا الإصدار ملف HTML واحد، لأن التنسيق والبرمجة مضمنان داخله.

## تنبيه
هذا نموذج تجريبي ببيانات افتراضية؛ لا يتصل فعليًا بمنصة تذاكر أو شركة تأمين، ولا يصدر وثائق أو قرارات مطالبات حقيقية.
